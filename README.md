# compline_app

A command-line style utility app built with Flutter.

## Highlights

- Terminal-inspired interface rendered with Flutter widgets.
- Demonstrates that CLI interaction patterns can be reproduced on mobile and desktop.

## Tech Stack

| Concern | Choice |
|---|---|
| UI | Flutter, Material |
| Platforms | Android, iOS, Web, Desktop |

## Project Structure

```
lib/
- `main.dart`
```

## Getting Started

### Prerequisites

- Flutter `>= 3.16` (Dart `>= 3.2`)

### Run

```bash
git clone https://github.com/developer-rahim/compline_app.git
cd compline_app
flutter pub get
flutter run
```

### Test

```bash
flutter test
flutter analyze
```
